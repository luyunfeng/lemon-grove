# 技术绘图 V2.3.0

默认推荐的绘图 Skill。把自然语言逻辑转换为架构、泳道、时序、ER 等 16 类技术图，复用包内色板、字体、图型布局和参考图，不依赖制作聊天。

- [技能入口](SKILL.md)：图型选择、绘图流程与按需交付。
- [安装和验证](INSTALL.md)：依赖、技能目录、16 类参考复现及调用示例。
- [运行环境](references/runtime.md)：Linux 验证条件、字体后端及 SVG-only 模式。
- [工具交接](references/tool-handoff.md)：用现有飞书 Skill/CLI 接收既有 SVG。
- [迭代验证](references/self-evolution.md)：参考回归、陌生任务独立评审与维护。

典型请求：

> 使用 lark-tech-diagrams-v2，把下面的逻辑画成技术图：……

> 使用 lark-tech-diagrams-v2，把下面的逻辑画到指定飞书文档：……

同输入参考检查应通过 16 类 SVG 字节核对；新业务还需实际看 PNG，核对事实、方向、分支、基数及连线。示例是虚构业务，必须替换为用户逻辑。输出放在仓库和 Skill 之外。

包内保留绘图代码、语义/几何检查、模板、参考图和附许可的字体。身份、授权、文档创建、上传和服务端回读由现有工具承担。当前完整验证环境为 Linux；其他平台和连接器拖动绑定需另行验证。
