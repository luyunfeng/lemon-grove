# 运行环境与包内容

核心绘图需要Python 3.11+和Pillow；已测Python3.12、Pillow12.3.0。本地PNG预览使用CairoSVG2.9.0及其Cairo运行库。按requirements.txt安装Python依赖；Cairo库的安装交给环境包管理器。不要复制工具运行时、虚拟环境、登录态或npm缓存进Skill。

包内assets/fonts包含原始Noto Sans CJK常规/粗体字体及SIL OFL许可。排版使用这份字体，缺失会明确失败，不改用字符宽度估算。预览通过临时私有fontconfig读取包内字体，不修改系统字体或全局配置。PNG预览在其他操作系统上仍需字体兼容检查；SVG几何和文字保留为主要产物。

如果只需要SVG，或预览库尚未安装，可用quick_draw.py render的--svg-only选项。它仍做布局/语义检查，但返回preview=null；不得把这种状态称为已经看图。补齐兼容SVG预览工具后再完成视觉验收。

包内保留：短入口、图型/输入/风格契约、排版和离线检查脚本、16类模板与参考图、去重后的回归输入、色板、字体及许可。包外保留：个人账号和目录、上传授权实现、云端收据、绝对实验路径、逐轮长报告、安装器及历史备份。绘图器没有网络访问或飞书API调用。

新环境的一条复现检查：`python3 <技能目录>/scripts/check_examples.py --out <新任务目录>`。它读取包内字体、色板和16类输入，核对几何/语义与参考SVG字节一致。它不调用飞书或读取历史实验，也不把新逻辑的正确性等同于模板复现。

已测预览后端为Linux Cairo + Fontconfig。其他后端必须确认它会采用包内常规/粗体字体；未验证前使用--svg-only并交给兼容预览工具，不能仅凭Python包安装成功声称PNG一致。文本模板、JSON及SVG始终以UTF-8读写。
