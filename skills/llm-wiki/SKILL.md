# llm-wiki（定位用）

1. 从当前工作目录向上查找包含 `AGENTS.md`、`wiki/index.md` 和 `raw/` 的知识库根目录。
2. 当前目录不属于知识库时，使用用户明确指定的本地路径；路径未知时询问用户，不硬编码账号或机器目录。
3. 完整阅读该仓库根目录的 `AGENTS.md` 并严格遵守。所有规则只以该文件为准，本 skill 不复制规则。
