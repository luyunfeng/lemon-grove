# 知识库概览

> 我在学什么、每个领域掌握到什么程度、还有哪些问题没想清楚。页面按知识点组织，完整目录见 index.md，本库的用法见「本知识库的设计与用法」。

## 在学的领域
| 领域 | 掌握程度 | 从哪页读起 |
|---|---|---|
| Agent 工程方法 | 主线已经清楚：上下文、驾驭（harness）、验证、外层循环、规格前置，各自解决什么问题、怎么组合 | Agentic Engineering（智能体工程） |
| Agent Skills | 能判断什么值得做成 Skill、怎么写、怎么测；自进化还停留在理解原理 | Agent Skill |
| 模型训练与评测 | 理解可验证奖励为什么让 Coding 先突破，会读模型发布和评测榜单 | 可验证奖励 |
| 个人知识管理 | 本库就是实践：一页一个知识点，关联靠标签和实体来找 | LLM Wiki 模式 |
| 工具与项目 | Claude Code、Codex 日常在用；ECC、Superpowers 等框架拿来借鉴做法 | Claude Code |
