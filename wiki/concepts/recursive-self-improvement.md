# 递归自我改进

> 递归自我改进（Recursive Self-Improvement，RSI）指 AI 系统实质性地参与构建下一代更强的系统，更强的系统又进一步加速改进，形成自我加速的循环。它要回答两个问题：这种循环在工程上会先以什么形态出现；以及当研发速度自我加速时，人还能不能保持干预能力。

## 要点
- **近中期更可能是模型改进自己的 harness，而不是直接重写权重**。工作流、工具、权限、上下文、持久记忆、评测和可观测性都是代码和文本，可以在受控环境里被修改、测试、回滚；权重层的自我改写证据还很早。
- **优化对象有一条阶梯**：指令提示 → 结构化上下文 → 工作流 → harness 代码 → 优化器代码（「如何优化 harness」本身）→ 模型权重 → 完整的 RSI 循环。模型越强，被优化的对象越往阶梯上方走。
- **递归结构本身不保证变好**。底座模型不够强时，递归优化可能越改越差；「会提出改进」和「能从改进中受益」是两种不同能力。
- **核心问题是干预能力**：人能否在能力提升的同时始终保持有效干预。「干预能力」怎么定义、怎么度量，目前没有答案。
- **单方面暂停不现实**。在竞争格局里，谁先停谁落后，集体暂停又缺乏可信的承诺和监督机制，是典型的囚徒困境。

## 怎么做 / 为什么

### 1. 三种可能的走向
| 情景 | 含义 | 需要什么 |
|---|---|---|
| 曲线变平 | 能力提升遇到瓶颈，递归改进自然停滞 | 不需要外部干预 |
| 人类掌舵 | 人保持对研发过程的有效干预，控制方向和速度 | 可度量的干预能力、放在循环外的验证与权限 |
| 完整 RSI | AI 完全自主递归改进，人失去干预能力 | 这是要避免的情形 |

「人类掌舵」这条路在工程上是具体的：它要求每一层自我改进都满足 Skill 自进化里的那几条纪律，即有界改动、验证门控、失败留证据、验证器和权限不在被优化的范围内、人审批。

### 2. 为什么先出现在 harness 层
- Harness 的本质是代码：它描述了提示、工具调用、子 Agent、控制流、记忆和评测如何组合，天然可以被模型读写。
- 改 harness 的成本低、可回滚、可以做留出集回归；改权重则面临训练稳定性、目标被刷分、实验变量混杂等问题。
- 已有的做法包括：优化「改进器」本身的递归优化器；让 Agent 修改自己的 harness 代码仓库、评测通过后加入候选池的开放式演化；以及同时考虑 harness 更新和模型参数更新的联合优化（这一类证据最少）。

### 3. AI 参与 AI 研发的信号
前沿实验室披露的指标方向一致：模型能独立完成的任务时长在快速增长；工程团队里由模型产出的代码占比已经很高；在部分研究任务上模型能显著加速实验、在一些人类曾走过弯路的决策点上给出更优选择。这些指标的口径由实验室自己定义，难以独立核实，但它们说明「AI 参与 AI 研发」已经从边缘走向核心。

衡量「AI 做研究」的能力有专门的基准，例如复现论文、计算可复现性、数据驱动科学发现、机器学习工程竞赛、GPU kernel 编写等。一个有代表性的观察是：在短时间预算下 Agent 表现强，在长时间预算下人类专家的回报更好。

### 4. 为什么单方面暂停不现实
- **人才流失**：顶尖研究者会流向没停的对手。
- **资本撤离**：投资者不会等一个自我冻结的公司。
- **技术断层**：停几个月再追，可能再也追不上。

即使集体暂停，也有代价：
- **安全研究也会停**：对齐和可解释性研究同样依赖前沿模型。
- **黑箱化**：公开实验室停了，封闭研究继续，反而失去透明度。
- **定义困境**：什么算「前沿」难以界定，监管总是慢于创新。
- **地缘套利**：一方停、另一方不停，最终被迫重启且更激进。

更深一层：如果 RSI 已经在发生，暂停可能已经太晚；AI 辅助研发的效率一旦成为基础设施，就很难退回去。

### 5. 自我改进系统面对的七个挑战
1. **弱且模糊的评测器**：研究品味、长期科学价值、真实业务价值都难用快速验证器衡量。
2. **上下文与记忆的生命周期**：Agent 越独立，记忆越膨胀，管理记忆本身会变成能力的一部分。
3. **负结果**：系统必须能保存和承认失败，用失败缩小搜索空间。
4. **多样性塌缩**：进化和强化学习会反复利用已知的高奖励模式，开放式探索需要刻意维持。
5. **奖励作弊**：奖励来自单测、评审模型或基准时，Agent 可能学会针对奖励源作弊。
6. **长期成功**：短期完成任务不等于长期维护健康，可维护性、所有权、迁移成本很难被短期沙箱奖励捕捉。
7. **人的角色**：人不应从循环中消失，而应上移到更合适的抽象层，在关键决策点提供方向和监督。

## 边界与误区
- **误区：RSI 就是模型自己改权重、突然「觉醒」。** 现实的形态是模型在受控环境里改进 prompt、上下文、工作流、工具、记忆、权限和评测。
- **误区：「AI 写出论文」等于「AI 做出科学发现」。** 自动研究系统能产出像样的稿件，但仍可能有伪造引用、实现悄悄偏离原方法、实验薄弱等问题。常见的失败模式还有：套用训练数据里的过时默认做法、长程任务丢失关键细节、实验失败时仍宣布成功、缺乏判断重要基线的领域直觉、实验能跑但没回答正确问题。
- **误区：只要有人在审批就算「人在掌舵」。** 如果验证器、权限、评测都在被优化的范围里，人看到的只是被优化过的结果。干预能力要求人控制的是循环的边界，而不只是最后一步的按钮。
- **取舍：呼吁暂停的动机。** 在自身领先时呼吁全球暂停，可能是真诚的风险担忧，也可能是锁定优势、争夺规则话语权的博弈；判断时看的是有没有可信的协调与核查机制，而不是表态本身。
