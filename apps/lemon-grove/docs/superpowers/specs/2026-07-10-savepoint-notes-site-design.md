# SAVEPOINT 个人笔记展示站设计说明

## 概要

创建一个名为 **SAVEPOINT / 存档点** 的单页个人笔记展示站。网站展示工作、学习、生活三类预置笔记，不提供新增、编辑、登录或云端保存能力。整体视觉沿用参考图的复古游戏机语言，同时保证长文本阅读舒适。

## 目标

- 让首页第一眼像一台可操作的复古游戏机，而不是通用博客模板。
- 用真实、自然的中文示例内容展示工作、学习和生活笔记。
- 让用户可以搜索、筛选、选择并阅读笔记。
- 在桌面和手机上都保持清晰的层级、可读性与可操作性。
- 构建完成后发布为私有 Sites 链接。

## 非目标

- 不提供笔记的新增、编辑、删除或持久化。
- 不接入账号、数据库、外部内容源或上传能力。
- 不做多页面路由、评论、分享或协作功能。

## 视觉方向

采用「存档卡带」方案：

- 背景为带细小十字点阵的暖米白纸面。
- 主要面板使用近黑色粗描边和向右下偏移的硬阴影。
- 砖红色作为选中态、主要按钮和重点信息的唯一高饱和强调色。
- 字体以清晰的中文无衬线体为主，站点标题可使用较有印刷感的衬线体。
- 卡片切角、顶部凹槽、状态灯和像素化标记通过 CSS 完成，不使用装饰性 SVG。
- 动效短促克制：按钮按下时阴影收回，卡片选择时轻微位移，遵循减少动态效果设置。

建议色板：

| 用途 | 色值 |
| --- | --- |
| 页面底色 | `#F3EBDD` |
| 面板底色 | `#FFF9ED` |
| 主文字与描边 | `#17130F` |
| 强调红 | `#C7352A` |
| 辅助棕灰 | `#756B60` |
| 分隔线 | `#D8C7A9` |

## 页面结构

### 顶部主机栏

- 左侧显示像素化卡带标记、`SAVEPOINT` 与中文名「存档点」。
- 中间提供 `全部 / 工作 / 学习 / 生活` 分类切换。
- 右侧显示 `09 SLOTS`、`READ ONLY` 等游戏机状态信息。

### 开场面板

- 主标题为「把日常存进这里」。
- 副文案说明这里收录工作片段、学习所得与生活碎片。
- 展示总笔记数、分类数和精选存档数三个简短指标。

### 笔记控制台

- 顶部是带游戏机面板感的搜索框，支持按标题、摘要、正文和标签过滤。
- 桌面端左侧为笔记卡带列表，右侧为当前选中笔记的阅读面板。
- 笔记卡显示存档编号、分类、标题、摘要、日期、阅读时长和标签。
- 阅读面板显示完整标题、元信息、正文分段和标签。
- 手机端改为单列；选择卡片后将阅读面板自然排在列表下方。

### 底部状态栏

- 显示「END OF LOG」、当前可见笔记数量和展示版说明。
- 不放通用营销链接或无实际用途的社交图标。

## 示例内容

共准备九篇中文笔记，每类三篇：

- 工作：项目启动清单、会议记录不等于决策、一周复盘。
- 学习：卡片笔记法实验、一本书的阅读摘记、CSS 布局练习。
- 生活：雨天散步路线、周末咖啡清单、这个月想记住的五件事。

每篇笔记包含足够完整的正文，避免 lorem ipsum 或模板化占位文案。

## 组件与职责

- `Page`：保存当前分类、搜索词和选中笔记，组合整个单页。
- `TopBar`：显示品牌、分类导航和只读状态。
- `IntroPanel`：呈现站点主张和统计信息。
- `SearchPanel`：接收搜索输入并提供清空操作。
- `NoteCard`：展示笔记摘要并触发选择。
- `ReaderPanel`：只负责渲染当前选中笔记的完整内容。
- `EmptyState`：搜索或筛选无结果时提供明确反馈和重置入口。

组件仅通过明确的属性传递数据与事件，不依赖外部服务。

## 数据与交互流程

1. 页面从本地常量加载九篇预置笔记。
2. 分类和搜索词共同生成可见笔记列表。
3. 用户选择卡片后更新当前笔记，阅读面板同步刷新。
4. 若筛选后当前笔记不可见，自动选择过滤结果中的第一篇。
5. 若没有匹配结果，显示空状态，不保留失效的阅读内容。

所有交互只存在于当前页面会话中，刷新后恢复默认展示状态。

## 响应式与无障碍

- 桌面端采用列表与阅读区的双栏结构；窄屏切换为单列。
- 导航在小屏横向滚动，点击目标保持足够大。
- 所有交互元素使用原生按钮或输入控件，并提供可见焦点状态。
- 颜色对比满足正文阅读要求，信息不只依赖颜色表达。
- 搜索框具有明确标签，空状态和结果数量可被辅助技术理解。
- 支持键盘完成分类、搜索、选择和重置操作。

## 异常与空状态

- 网站不请求网络数据，因此不需要加载失败或重试流程。
- 搜索无结果时显示「没有找到这个存档」，并提供一键清除筛选。
- 过长标题和标签在卡片中安全换行，不截断阅读面板正文。
- JavaScript 不可用时仍呈现站点标题和基础内容结构。

## 技术实现边界

- 使用 Sites 初始化的单页 React/Vinext 项目。
- 主要实现集中在一个页面组件、少量局部组件和全局样式中。
- 不增加数据库、身份验证、图片生成或额外运行时依赖。
- 使用 CSS 图形、字体、边框和布局完成游戏机效果。
- 保留 Cloudflare Worker 兼容的 ESM 构建输出。

## 验收标准

- 首屏明确呈现 `SAVEPOINT / 存档点` 品牌与复古游戏机视觉。
- 页面包含九篇分属工作、学习、生活的完整示例笔记。
- 分类筛选、全文搜索、清空筛选和笔记选择均可用。
- 无结果状态正确出现，重置后恢复默认内容。
- 桌面与手机布局无横向溢出，正文易读。
- 交互可通过键盘完成，并具有清晰的焦点反馈。
- 生产构建成功，发布后的页面可正常访问。
